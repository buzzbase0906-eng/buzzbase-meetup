### いちばん大事なルール

**同時に編集しないこと。** このサイトは1つのファイルでできているため、
2人が同じタイミングで編集すると、**あとから保存したほうの内容だけが残り、
もう片方の作業は消えます。**（Git の差分マージが効きません）

作業前にチームへ「今からサイト触ります」と一声かけ、
終わったら「終わりました」と伝える運用にしてください。

### 編集の手順

1. GitHub でこのリポジトリを開く
2. `index.html` を開いて編集（またはローカルに落として編集し、アップロード）
3. コミットすると **2分ほどで公開サイトに反映**されます
4. 反映確認は URL の末尾に `?v=数字` を付ける（キャッシュ回避）

## 中身を変えるときに触る場所

`index.html` の `<script>` の冒頭に、**設定用の定数**がまとまっています。
文言や日付を変えるだけなら、ここだけを直せば済みます。

| 定数名 | 内容 |
| --- | --- |
| `EVENT` | 開催日・時間・会場・定員 |
| `SITE` | サイト名・キャッチコピー・主催表記 |
| `LINKS` | 申込フォームURL・Instagram・連絡先メール |
| `CREW` | 運営メンバー（`show:false` で非表示にできる） |
| `PARTNERS` | パートナー・協賛（`logo` と `url`） |
| `NEWS` | お知らせ |
| `PROGRAM` | 当日のタイムテーブル |
| `STATS` | NUMBERS ページの数字 |
| `FAQ` | よくある質問 |
| `SHOW` | 各セクションの表示ON/OFF（`past` / `voice` / `sponsors`） |
| `PAST_GUESTS` | 参加者一覧ページの掲載者 |

### よくある編集の例

```js
// 開催日を変える
const EVENT = { date:"2026.09.25 FRI", ... }

// クルーを再表示する（show:false を消すだけ）
{show:false, code:"C-02", name:"SOTA INUI", ... }
   ↓
{code:"C-02", name:"SOTA INUI", ... }

// 申込フォームの送信先を変える
const LINKS = { entryForm:"https://...", ... }
```

## ⚠️ 壊さないでほしいもの

以下は理由があってそうなっています。**変える前に必ず相談してください。**

- **`noindex` の指定**（`<head>` 内）
  検索結果に出さないための設定です。外すと Google に載ります。
- **動画の遅延読み込み**（`preload="none"` と `data-src`）
  6.6MB の動画を最初から読むと、表示が20秒以上遅くなります。
  `preload="auto"` に戻さないでください。
- **`.brw` クラスの付いた `<br>`**
  PC でだけ改行するための仕組みです。ただの `<br>` に戻すと、
  スマホで不自然な位置に改行が入ります。
- **装飾の `z-index`**（`section:not(.hero) .floaters`）
  背景の飾りが本文の上に被らないようにしています。
- **参考サイトからの素材コピー**
  画像・ロゴ・音源・イラストを他所のサイトからコピーしないでください。
  自前の素材か、商用利用が許可されたものだけを使います。

## 限定公開について

- すべてのページに `noindex, nofollow` を指定しています
- どこからもリンクしていないため、**URL を知っている人だけ**が閲覧できます
- GitHub の無料プランでは非公開リポジトリを Pages で配信できないため、
  リポジトリ自体は公開されています。**パスワードや個人情報は絶対に書かないでください。**
