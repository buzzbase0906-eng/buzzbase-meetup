| ファイル | 内容 |

## 中身を変えるときに触る場所

`index.html` の `<script>` の冒頭に、**設定用の定数**がまとまっています。
文言や日付を変えるだけなら、ここだけを直せば済みます。

| 定数名 | 内容 |
| --- | --- |
| `EVENT` | 開催日・時間・会場・定員 |
| `SITE` | サイト名・キャッチコピー・主催表記 |
| `LINKS` | 申込フォームURL・Instagram・連絡先メール・運営会社サイト（`company`） |
| `CREW` | 運営メンバー（`show:false` で非表示にできる） |
| `PARTNERS` | パートナー・協賛のロゴ一覧（`logo` と `url`。`logo:null` なら社名が文字で出ます） |
| `PARTNER_FEATURES` | パートナーの紹介文（CREW ページ下部。上から順に表示） |
| `NEWS` | お知らせ |
| `PROGRAM` | 当日のタイムテーブル |
| `STATS` | NUMBERS ページの数字 |
| `FAQ` | よくある質問 |
| `SHOW` | 各セクションの表示ON/OFF（`past` / `voice` / `sponsors`） |
| `EVENT_ENDED` | 開催が終わったら `true`。申込ボタンの文言・Status・ENTRY ページ・トップが「終了しました」表示に一括で切り替わります |
| `VIDEO_VISIBLE` | ティザー映像を出すかどうか。`false` でトップの映像と申込後の映像がまとめて消えます |
| `REPORT_VISIBLE` | 開催レポートのページ（`#/report`）をナビに出すかどうか |
| `HALLOWEEN` | ハロウィン仕様のON/OFF。`true` のあいだはサイト全体が夜（黒紫の地＋オレンジ・紫）になり、星・月・コウモリ・クモの巣・ゴースト・かぼちゃが出ます。`false` に戻すと白地×赤・黒の通常版に戻ります。中身は `html.hw` のCSSに閉じてあるので、各ページには手を入れていません |
| `GUESTS` | 出演ゲスト（`sns:"tiktok"` や `url:` でリンク先を変更） |
| `GUESTS_VISIBLE` | 出演ゲストのページ（`#/guests`）を出すかどうか |
| `SHARE_VISIBLE` | 参加表明の画像づくり（`#/entry` の下部）を出すかどうか |
| `MQ_FACTS` / `MQ_CTA` | 流れる帯に出す文言。`{en:"英字", ja:"日本語", hot:true}` の配列 |
| `GUEST_PHOTOS` | 出演ゲストの写真（Instagram ID がキー） |

## ⚠️ 壊さないでほしいもの

以下は理由があってそうなっています。**変える前に必ず相談してください。**

- **`CNAME` ファイル**
  中身は `buzzbase.net` の1行だけです。消すと独自ドメインが外れ、
  URL が `buzzbase0906-eng.github.io/buzzbase-meetup/` に戻ります。
- **`<head>` の検索まわり一式**（title / description / OGP / JSON-LD）
  検索結果とSNSシェアの見え方を決めています。消すと検索に出にくくなります。
  非公開に戻す手順は、このファイルのいちばん下に書いてあります。
- **動画の遅延読み込み**（`preload="none"` と `data-src`）
  6.6MB の動画を最初から読むと、表示が20秒以上遅くなります。
  `preload="auto"` に戻さないでください。
- **`.brw` クラスの付いた `<br>`**
  PC でだけ改行するための仕組みです。ただの `<br>` に戻すと、
  スマホで不自然な位置に改行が入ります。
- **装飾の `z-index`**（`section:not(.hero) .floaters`）
  背景の飾りが本文の上に被らないようにしています。
- **参考サイトからの素材コピー**
  画像・ロゴ・音源・イラストを他所のサイトからコピーしないでください。
  自前の素材か、商用利用が許可されたものだけを使います。

**このサイトは検索結果に出る設定になっています。**

- `index.html` の `<head>` に、タイトル・説明文・OGP・イベントの構造化データ（JSON-LD）を入れています

## セキュリティ

### 自動で入るもの（触らなくていい）

**CSP（Content-Security-Policy）** は `index.html` の `<head>` にある meta 1行です。
中身は「このファイルに書いてあるスクリプトそのもの」のハッシュで、外から差し込まれたスクリプトは動きません。

`index.html` の中身を少しでも書き換えたら、**必ず `python3 csp_fix.py` を実行してハッシュを計算し直してください**
（同じフォルダに置いてあります）。これを忘れると、ブラウザがスクリプトをブロックしてページが真っ白になります。
このスクリプトは meta が2つ以上あったときの整理も同時にやります。

```
default-src 'none' …… 既定ではどこからも読み込まない
script-src  sha256-… …… このファイルの中のスクリプトだけ
style-src   'self' 'unsafe-inline' fonts.googleapis.com
font-src    fonts.gstatic.com
img-src     'self' data:
connect-src 'self' …… 外部へのデータ送信を禁止
```

**やってはいけないこと**

- `<meta http-equiv="content-security-policy" …>` を手で書き換える
- **CSP の meta を2つ以上にする**。ビルドを重ねると増えてしまうことがあります。
  ブラウザは全部を同時に満たすものしか実行しないため、古いものが1つでも残っていると
  ページが真っ白になります。`<head>` に1つだけであることを必ず確認してください
- HTML に `onclick=` `onload=` などのイベント属性を直接書く（CSP で動かなくなります）。
  JavaScript は `<script>` の中にまとめて書いてください
- 外部のスクリプト（解析タグ、広告タグなど）を貼る。
  必要になったら `csp_fix.py` の `TEMPLATE` に、そのドメインを足してから実行し直してください

### GitHub Pages では設定できないもの

`X-Frame-Options`（他サイトへの埋め込み防止）と `Strict-Transport-Security` は
HTTPヘッダーでしか設定できず、GitHub Pages では付けられません。
これが必要になったら、Cloudflare を前に置くか、別のホスティングへ移す必要があります。

### 出演ゲストの表示・非表示

**`index.html` には、掲載の了承が取れている方のデータだけを置きます。**
掲載を希望されない方は、名前も Instagram ID も写真もこのファイルに入れません。
このリポジトリは公開なので、「出さない人のリスト」をここに書くと、
出したくないという希望そのものが誰にでも読めてしまうためです。

名簿の全員分（出す人・出さない人）は **`guests-admin.html`（管理ツール）** が持っています。
このファイルは**リポジトリに置いていません**。運営の手元に置いて、
ダブルクリックで開いて使ってください。

1. `guests-admin.html` を開く
2. スイッチで表示・非表示を切り替える（作業中の状態はブラウザに自動保存されます）
3. 「設定を書き出す」→「コピー」
4. 出てきた **`const GUEST_PHOTOS = {…};`** と **`const GUESTS = […];`** の2ブロックを、
   `index.html` の同じ名前のブロックにまるごと貼り替える
5. **CSP のハッシュを計算し直す**（`python3 csp_fix.py`。下の注意も参照）
6. ページ自体を出す・引っ込めるのは `GUESTS_VISIBLE` で切り替えます

### ページの作りと URL（ここが大事）

ページのURLは `/about/` のような**実在するパス**です。
サイト自体は `index.html` 1つで全ページを描いていますが、それだけだと
Google から「1ページしかないサイト」に見えてしまいます。
そこで **`build_pages.js` が、ページごとの HTML ファイルを書き出します**。

**`index.html` を直したら、必ずこの2つを順番に実行してください。**

```
python3 -m http.server 8905     # 別のターミナルで、このフォルダを開いたまま
node build_pages.js
```

`build_pages.js` がやること

- `/about/index.html` のようなファイルを12ページぶん書き出す
- トップ（`index.html`）と `404.html` にも、本文をあらかじめ入れておく
- ページごとの `<title>`・説明文・canonical・OGP・構造化データを差し替える
- `sitemap.xml` を書き直す
- **CSP のハッシュも中で計算し直す**ので、このあと `csp_fix.py` を実行する必要はありません

ページのタイトルと説明文は `build_pages.js` の先頭にある `PAGES` に書いてあります。
ページを増やすときは、`index.html` の `PAGES`／`NAV` に足したうえで、
`build_pages.js` の `PAGES` にも1行足してください。

書き出したフォルダ（`about/` `ticket/` など）も GitHub に上げてください。
上げ忘れると、そのURLだけ 404 になります。

以前に配った `#/about` 形式のリンクもそのまま開けます（自動で `/about/` に直ります）。

ファビコンとホーム画面用のアイコンは `build_icons.js` でつくっています。

### 流れる帯（マーキー）

ホームに2本あります。ヒーローの下（白地）と、申込セクションの直前（黒地）です。
文言は `MQ_FACTS` と `MQ_CTA` を書き換えるだけで変わります。
`marquee(items, {tone:"dark"|"grad", sec:40})` で色と速さを指定します
（`sec` は1周にかける秒数。大きいほどゆっくり）。
同じ内容を2つ並べて片方ぶんだけ動かすことで、途切れないループにしています。
動きを減らす設定の端末では止まり、マウスを乗せている間も止まります。
読み上げには出していません（同じ内容がページ本文にあるため）。

### 参加表明の画像づくり

`#/entry` の下部にあります。名前と Instagram ID を入れると、
参加表明の画像（正方形 1080×1080 ／ ストーリー 1080×1920）をその場でつくれます。

**入力された内容はブラウザの中だけで使い、どこにも送信していません。**
画像は canvas に描いてそのまま保存するだけなので、サーバーには何も残りません。
この点は画面にも明記してあります。文言を変えるときも、送信しない旨は残してください。

デザインを直すときは `SH_LAYOUT`（サイズごとの座標）を触ります。
ロゴはページに埋め込んである SVG をそのまま画像化して使っているので、
ロゴを差し替えると画像のほうも自動で変わります。
